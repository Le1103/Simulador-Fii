Simulador de Investimentos em Fundos Imobiliários

Sobre o projeto

Este projeto consiste na criação de uma ferramenta simples em Excel para simular investimentos em Fundos Imobiliários (FIIs).

A planilha permite calcular o valor total investido, o patrimônio acumulado e os dividendos mensais, ajudando o usuário a entender melhor o impacto dos investimentos ao longo do tempo.

Objetivo

O objetivo do projeto é aplicar os conceitos de Excel no desenvolvimento de uma ferramenta prática de simulação de investimentos, utilizando cálculos financeiros para apresentar uma estimativa dos resultados de um investimento em FIIs.

Funcionalidades

* Cálculo do valor total investido;
* Cálculo do patrimônio acumulado;
* Estimativa dos dividendos mensais;
* Simulação de investimentos ao longo do tempo;
* Organização das informações para facilitar a análise dos resultados.

Aprendizados

Durante o desenvolvimento do projeto, pude praticar conceitos de Excel e cálculos financeiros, além de aprender a organizar e documentar um projeto utilizando o GitHub.

Também foi possível entender melhor como uma planilha pode ser utilizada para automatizar cálculos e facilitar a visualização de possíveis resultados de investimentos.
